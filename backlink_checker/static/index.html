Simple guide

  1. Your website Type the site you own — the one you want to find links to. Example: mysite.com
  2. Website to scan Type the other site where you think your link might appear. Example: a blog or directory.
  3. Entire website Checks many pages on that site automatically (best for most people).
  4. Specific URLs Use this only if you already have a list of exact page links to check.
  5. Deep JS render Turn ON if the other site is a modern app that loads content slowly. Leave OFF for normal blogs (faster).
  6. Start full-site scan Press this to begin. Watch the numbers: with link means we found your backlink.
  7. Download CSV Save the full report to open in Excel or Google Sheets.

Tip: Green Y = your link is there. Grey N = not on that page. This tool checks one site you choose — it does not search the whole internet.
